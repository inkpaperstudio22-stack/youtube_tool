Privacy Policy

Studio Uploader · Last updated 4 November 2026

Studio Uploader is a private tool run by Ink Paper Studio in Switzerland. It publishes videos to, and reads analytics for, YouTube channels that it owns. It has no other users. This policy explains what data it touches and how.

Use of YouTube API Services

Studio Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is covered by the Google Privacy Policy.

Data accessed

Studio Uploader asks Google for three permissions:

  • youtube.upload: to upload videos and set their title, description, tags and publish time.
  • youtube: to set thumbnails, correct video details after upload, add videos to the owner's playlists, and confirm which channel is signed in.
  • yt-analytics.readonly: to read aggregate reports (such as views, watch time, retention and traffic sources) for the owner's own channels.

It does not read comments, messages, subscriber lists or any data about individual viewers. It does not access other people's channels.

How data is used

Data is used only to publish the owner's videos and to show its channel statistics on a private dashboard on the owner's own computer. It is not sold, shared, used for advertising, or combined with data from other sources.

Storage and security

  • Google sign-in tokens are stored only on the owner's computer and are never sent anywhere except to Google.
  • Analytics data is stored locally on the same computer for the dashboard. Cached YouTube data is refreshed or deleted within 30 days, as YouTube's developer policies require.
  • No data is stored on external servers, and no cookies or tracking are used on this website.

Sharing

No data is shared with third parties. The only exchange of data is directly between Studio Uploader and Google's APIs.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. After access is revoked, the stored tokens stop working and the local copies of tokens and analytics data are deleted. To ask for deletion, write to the contact address below.

Changes

If this policy changes, the date at the top of this page will be updated.
